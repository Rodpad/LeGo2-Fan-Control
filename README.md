**Description**

Full unrestricted fan control for the Lenovo Legion Go 2.

LeGo2 Fan Control allows you to bypass the default system restrictions and take complete charge of your device's cooling system. Whether you want a whisper-quiet experience for light browsing or maximum cooling for heavy gaming, this tool gives you the freedom to set custom fan curves based on your APU temperature.


**Key Features**

Custom Fan Curves: Set precise RPM targets across six different temperature points. This includes the ability to set fan speeds below the hardware-enforced minimums at any temperature.

Stepped Fan Curve: Lock fan speeds to distinct levels rather than constantly ramping up and down. This helps reduce audible pitch whine.

Fan Smoothing: Delay fan changes (up to 9 seconds) to ignore sudden, short-lived temperature spikes.
